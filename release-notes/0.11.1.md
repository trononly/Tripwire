## What's new
- Send Money and Pochi La Biashara now keep separate favourites, so each flow shows only its own people
- Paybill and Buy Goods keep separate Lipa favourites too
- The add tile now comes first in the favourites row
- Favourites are square, borderless tiles with quieter initials, so the names are easier to scan

Your existing Send favourites are kept under Send Money. Pochi starts with an empty list, so add the numbers you use there once.
