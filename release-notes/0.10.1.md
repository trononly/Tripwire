## What's new
- Send Money and Pochi La Biashara now have favourites: tap a saved recipient to fill the number, then send as usual
- Add a favourite from the Android contact picker or type a name and number by hand - no contacts permission is needed
- Manage favourites in a new drawer: add, rename, remove, and see an empty state until you save the first one
- Contact numbers now accept `+254`, `254`, `00254`, `254 (0)` and bare 9-digit forms
- The in-app What's new card and Changelog now show curated release notes instead of a list of pull request titles
